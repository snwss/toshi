estrutura de um documento html

HTML é a linguagem de marcação padrão para criar páginas web,
descrevendo a estrutura e o conteúdo de uma página usando elementos (tags). As tags são escritas entre colchetes angulares < > e definem como o navegador deve interpretar e exibir o conteúdo. HTML é essencial para qualquer desenvolvedor web, pois permite a estruturação e formatação de textos, incluindo títulos, parágrafos, ênfase, citações e abreviações.
